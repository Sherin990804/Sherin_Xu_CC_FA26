在作业提交之后，我给本周的作业做了些更新

Sketch1

I used for() loops and an array to create and store a grid of numbers. With dist() and map(), numbers near the mouse glow brightly, while those farther away appear darker. The brightness gradually fades using boxed[index] *= 0.96, creating a glowing trail as the mouse moves.

Sketch2

I used async setup() and loadImage() to load 12 animation frames, and class Person to create characters with different positions and walking speeds. Each mouse click uses mousePressed() and push() to add five new characters to an array. The characters walk toward a door on the right, and window.location.href returns to the assignment page once everyone has entered.
